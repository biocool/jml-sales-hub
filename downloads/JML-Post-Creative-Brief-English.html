What is a post creative brief?

A Post Creative Brief is a short pre-production document that defines who a post is for, what it should achieve, what it should communicate, what will be delivered and who will approve it. It should give the production team enough direction to execute.

01 / CREATIVE BRIEF

The creative direction

Defines the objective, audience, insight, key message, tone and visual direction. It can cover a whole campaign or a single post.

02 / CONTENT BRIEF

The content requirements

Defines what to write or say: hook, structure, sources, required points and call to action. SEO details matter for many articles, but are not mandatory for every social post.

JML format: Post Creative Brief / Content Brief. This toolkit combines both. For graphics, specify slides and on-image copy. For video, add timecodes, shots, audio and captions.

How to use it

1. The content owner completes the brief. 2. Approve the objective, message and copy. 3. Start production. 4. Check the final asset against the acceptance criteria. 5. Record performance and learning after publication.

JML palette: #1A0030 / #3B0764 / #B8E000. Typography: DM Serif Display and DM Sans; local fallback fonts are used if these fonts are unavailable.

The master template

Create one independent brief per post. Mark irrelevant fields “Not needed.” A blank field is an unresolved decision.

Ready to start production?

  • The objective, audience, key message and CTA work together.
  • Copy or script is approved, and factual claims have sources.
  • Dimensions and aspect ratio are chosen. Check current platform specifications again before publishing.
  • Asset licenses, talent consent and accessibility requirements are clear.
  • The final approver, deadline and review rounds are agreed.
